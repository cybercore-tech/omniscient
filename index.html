The Cybercore contract

Schema-first.
Operator-ready.

Omniscient reads the same palette contract as every Cybercore surface. The page, the dashboard, and the reports speak in the same tokens — bg, fg, acid, cyan, pink, panel, line, muted.

Paths stay portable through XDG defaults, privileged modules ask clearly, and unavailable tools remain visible instead of becoming false green checks.

schema / cybergrid.json
{
  "schema_version": 2,
  "active": "neon-night",
  "surface": "omniscient",
  "paths": {
    "sysops_root": "~/.sysops",
    "report_root": "$XDG_STATE_HOME/omniscient"
  }
}
